# Genshin-Text-MUD# 

> 一款基于 C++17 开发的单机文字 MUD 游戏，以《原神》蒙德篇为背景进行简化改编。

## 项目简介

**《捕风的异乡人》** 是一个使用 C++ 开发的控制台文字冒险游戏。

玩家将作为旅行者进入提瓦特大陆，从鹰翔海滩开始探索蒙德地区，通过移动、对话、战斗、收集物品和推进任务，逐步解除风龙废墟的封印，并最终挑战风魔龙。

项目主要用于 C++ 面向对象程序设计与软件工程实践，重点实现：

- 面向对象的角色继承体系
- 文字 MUD 命令解析
- 地图与房间系统
- NPC 与剧情任务
- 回合制战斗
- 背包与装备
- 存档 / 读档
- STL 容器与算法
- 模块化多人协作开发
