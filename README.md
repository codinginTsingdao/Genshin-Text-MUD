# Genshin-Text-MUD

《捕风的异乡人》是一个使用 C++17 开发的单机文字 MUD 游戏，作为面向对象程序设计课程项目完成。

游戏背景参考《原神》蒙德地区。玩家将扮演旅行者，从鹰翔海滩出发，通过探索地图、与 NPC 对话、完成任务和进行战斗，最终前往风龙废墟挑战风魔龙。

## 功能介绍

- 文字 MUD 地图探索
- 东、南、西、北方向移动
- 世界地图与当前位置显示
- NPC 对话系统
- 主线任务推进
- 普通敌人与 Boss 战斗
- 回合制战斗系统
- 玩家等级、经验、生命值和摩拉
- 背包与物品系统
- 武器与护甲装备系统
- 消耗品使用
- 敌人掉落
- 游戏存档与读取
- 中英文命令输入
- Windows 控制台彩色输出

## 游戏流程

游戏主线围绕蒙德地区的风魔龙危机展开。

主要流程包括：

1. 从鹰翔海滩醒来
2. 前往森林小径并遇见安柏
3. 清理丘丘人营地
4. 进入蒙德城
5. 与琴、温迪等 NPC 对话
6. 前往风起地寻找净化材料
7. 解除遗迹中的封印
8. 进入风龙废墟
9. 挑战风魔龙
10. 完成最终剧情
